# CLAUDE.md

Guidance for Claude Code (claude.ai/code) working in this repository.

`common-license-lib` is a zero-runtime-dependency JVM library (Java 21) that gates software
under PolyForm Commercial-style terms: addresses on common free-mail providers pass without a
key, commercial domains must present a Keygen.sh license. It also builds LemonSqueezy checkout
URLs and verifies LemonSqueezy webhook signatures.

Published to Maven Central as `se.deversity.common:common-license-lib`.

## Invariants to check before you change anything

1. **No runtime dependencies.** `java.net.http.HttpClient` plus the in-tree `internal.Json`.
   JUnit is test-scope, VibeTags is compile-scope. Nothing else may reach the jar.
2. **Fail closed.** Any Keygen transport or authorization failure becomes
   `Denied(NETWORK_ERROR)` unless the consumer set `allowOnNetworkError(true)`.
3. **Constant-time signature comparison** via `MessageDigest.isEqual`. Never `String#equals`.
4. **Secrets never leak.** `LicenseConfig.toString()` redacts; keep them out of logs,
   exception messages and test fixtures.
5. **Dual build.** Both `mvn clean verify` and `./gradlew build` must pass. Version numbers
   live in two places and drift silently (see [docs/releasing.md](docs/releasing.md)).
